# ton-tolk-game

Пошаговая игра на блокчейне TON, написанная на языке Tolk.
Каждая транзакция с комментарием — это один ход.

## Описание

Игрок управляет персонажем через комментарии в транзакциях. Контракт обрабатывает команду, двигает игрока, врага и пулю, затем отправляет обновлённую карту в ответном сообщении.

## Правила игры

### Цель

Дойти до точки выхода в нижней части карты, избегая врага. Или уничтожить врага выстрелом из пушки.

### Управление

Отправляй TON на адрес контракта с комментарием:

- `w` — движение вверх
- `s` — движение вниз
- `a` — движение влево
- `d` — движение вправо
- `f` — выстрел (пуля летит вниз)

### Что на карте

- Стены — по периметру карты и горизонтальная стена с проходом посередине
- Игрок — стартует сверху, в проходе стены
- Враг — ходит влево-вправо в средней части карты
- Точка выхода — внизу карты, по центру

### Условия

- **Победа** — игрок достиг точки выхода или убил врага выстрелом
- **Поражение** — игрок встретился с врагом
- Враг двигается при каждой транзакции
- Пуля летит только вниз
- После победы или поражения игра завершается

## Устройство кода

### GAME_ID

Константа `GAME_ID` в начале контракта. Каждый раз при деплое меняй это число на другое — получишь новый адрес контракта. Это нужно, чтобы создавать новые игры после завершения предыдущей.

const GAME_ID = 1;  // меняй на 2, 3, 4...

### Хранилище

Все данные игры хранятся в одной структуре Storage и занимают 320 бит:

- gameId — идентификатор игры (32 бита)
- playerX, playerY — позиция игрока (64 бита)
- enemyX, enemyY — позиция врага (64 бита)
- enemyDirection — направление движения врага (32 бита)
- bulletX, bulletY — позиция пули (64 бита)
- bulletExists — существует ли пуля (32 бита)
- gameState — состояние игры: 0 = играем, 1 = победа, 2 = поражение (32 бита)

### Карта

Карта 8x8 задана прямо в коде рендера. Каждая клетка — один символ:

- `#` — стена
- _ — пол
- P — игрок
- E — враг
- X — точка выхода

Карта не хранится в контракте как данные. Она отрисовывается заново при каждом ответе на основе текущего состояния игры.

Ответ контракта

Контракт отправляет текстовое сообщение с картой. Если игра завершена — отправляет сообщение о победе или поражении вместо карты.

Размер сообщения

Ответное сообщение содержит:

- заголовок — 32 бита
- карта 8x8 — 64 символа по 8 бит = 512 бит
- переносы строк — 7 символов по 8 бит = 56 бит

Итого: 600 бит — помещается в одну ячейку TON (максимум 1023 бита).

Логика игры

Вся логика выполняется в функции onInternalMessage при каждой входящей транзакции:

1. Загружается текущее состояние из хранилища
2. Если игра завершена — выход без действий
3. Читается команда из тела сообщения (первый байт после префикса)
4. Двигается игрок по команде
5. Двигается враг влево-вправо
6. Двигается пуля, если она существует
7. Проверяются столкновения: игрок-враг, пуля-враг
8. Проверяется достижение точки выхода
9. Сохраняется новое состояние
10. Отрисовывается карта и отправляется ответ
